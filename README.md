# Vocabulary Apps Collection

A collection of interactive vocabulary presentations and games designed for students.

## Apps Included

### 🏗️ Wants and Needs
Explores basic concepts of things we want versus things we need to survive.

### 🏠 My House
Vocabulary related to furniture and rooms in a home.

### 🚶 The Youngest Marcher
Based on the story of the youngest marcher in the Birmingham Children's March.

## Tools

### 📸 Image Selector
A helper tool used to select and curate images for the vocabulary presentations.

## How to used
Simply open the `index.html` file at the root of this project to access all the applications.
